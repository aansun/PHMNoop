## Systemic patterns

- The cause line is the main failure: on green data she repeatedly reaches for a "short night / alcohol / hard block / disrupted rest" explanation (Stress, HRV, Resp, Weight pages) that the data contradicts. The model seems to treat the Explain beat as a requirement to name a problem.
- Comparators get mixed (yesterday vs 30-day vs baseline vs another day), so correct numbers are attached to wrong labels (Recovery, Strain, Skin, chat 8, 11, 12).
- The injected NEXT STEP is pasted onto surfaces it does not belong to and, for good readings, displaces the "habit that holds" step.
- Where a pack lacks a figure, prompt tokens ("NOT MEASURED", "dash", raw BLE status) leak into the answer.
