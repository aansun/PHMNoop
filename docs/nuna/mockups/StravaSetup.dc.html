Cara menyiapkan aplikasi Strava
1
Buka Strava, Pengaturan, My API Application.
2
Salin Client ID dan Client Secret ke kolom di atas.
3
Isi Authorization Callback Domain dengan localhost.
4
Simpan di sini, lalu ketuk Hubungkan Strava.
Callback URI
noop://localhost/strava/callbackSalin

Izin yang diminta: activity:write dan activity:read_all.
